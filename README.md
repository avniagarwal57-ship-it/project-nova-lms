## 🌟 Core Architectural Pillars

### 1. The Seven Learning Worlds
Replace traditional categories with planetary domains:
- 💻 **Programming World:** Algorithmic complexity, TypeScript metaprogramming, Rust systems, and architecture.
- ⚡ **Technology World:** Autonomous agent swarms, vector embeddings, hybrid RAG, cloud fabrics, and cyber defense.
- 🎨 **Design World:** Spatial UI engineering, fluid micro-interactions, dark-first aesthetics, and design tokens.
- 💼 **Business World:** Venture architecture, unit economics, defensible moats, and product-market velocity.
- 🔬 **Science World:** Theoretical astrophysics, computational neuroscience, and synthetic biology.
- 🧠 **Personal Development World:** Circadian cognition, deep flow state engineering, and mental stamina.
- 🗣️ **Language World:** Neural linguistics, polyglot fluency protocols, and machine translation pipelines.

---

### 2. 6-Stage Quest-Based Learning Engine
Transform courses into interactive multi-stage quests:
1. **Stage 1 (Discover Concept):** Narrative mission briefing and target objectives.
2. **Stage 2 (Visual Architecture):** Interactive SVG node diagram with clickable data projections.
3. **Stage 3 (Deep Dive):** Comprehensive rich text, embedded media, and key takeaways.
4. **Stage 4 (Live Code Sandbox):** In-browser TypeScript/JS code editor with automated test-case runner and terminal logs.
5. **Stage 5 (Knowledge Challenge):** Adaptive checkpoint quiz with instant explanations and timer.
6. **Stage 6 (Quest Completion):** Celebratory cosmic fanfare with XP burst, badges, and automated stage unlock.

---

### 3. Interactive Neural Skill Tree
- Visually connected dependency graph of foundational and advanced skills.
- Node state indicators: **Mastered** (glowing emerald), **In Progress** (pulsing cyan), **Locked** (dimmed with padlock).
- Prerequisite validation and direct 1-click **Launch Skill Mission** actions.

---

### 4. NOVA AI Mentor (5 Dedicated Pedagogical Modes)
Built-in AI companion with context-aware learning modes:
- 💡 **Explain Mode:** Step-by-step intuitive breakdown with real-world analogies (ELI5).
- 🎯 **Practice Mode:** Interactive exercises with guided, progressive hints.
- ⚔️ **Challenge Mode:** High-stakes knowledge duel against the AI with scenario scoring.
- 🔄 **Revision Mode:** Spaced-repetition recall of earlier missions and mathematical formulas.
- 📋 **Exam Mode:** Timed assessment simulation with rubric evaluations.
*Supports Google Gemini API via secure server-side proxy or intelligent offline demo engine.*

---

### 5. Multi-Axis Competency Skill Radar
- Real-time SVG polygon radar mapping strengths and growth areas across 6 core domains.
- Personalized learning velocity tracking and automated next-mission recommendations.

---

### 6. Social Learning Hub & Guilds
- **Collaborative Study Guilds:** AI Swarm Architects, Orbital Full-Stack Guild, Quantum Collective.
- **Community Feed:** Discussion threads, question broadcast, and achievement celebrations.
- **Peer Moderation:** Reporting and safety controls.

---

## 🛠️ Tech Stack & Architecture

- **Frontend:** React 18, TypeScript, Tailwind CSS, Lucide Icons, Canvas-Confetti, Web Audio API Synthesizer.
- **Backend:** Express API, TypeScript runtime, Node.js.
- **Database:** Atomic JSON persistent storage with live API serialization.
- **Build & Bundle:** Vite 6 with TypeScript compilation (`tsc && vite build`).
- **Deployment Target:** Vercel (serverless rewrite via `api/index.ts` and `dist`).

## ⚡ Quick Start (Local Development)

```bash
# Clone the repository
git clone https://github.com/avniagarwal57-ship-it/project-nova-lms.git
cd project-nova-lms

# Install dependencies
npm install

# Start development server (API + Client concurrently)
npm run dev

# Run integration test suite
npm test

# Build production bundle
npm run build
```
